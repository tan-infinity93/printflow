--- Previously listed as "Half-Built" ---

1. VERSION HISTORY — RESTORE
   OLD: "Restore from a version is a stub (window.alert('Loading Version...'))"
   ACTUAL: Fully implemented. `restoreVersion(versionId)` in scripts.js fetches
   the snapshot from printingVersionLogs IndexedDB store, clears the content-layer,
   reconstructs all DOM elements via `jsonToDom()`, re-attaches drag/context-menu
   interactions for all element types, and logs the restore action to the audit log.
   stats.js renders version items as clickable rows with human-readable timestamps.
   STATUS: COMPLETE ✅

2. PRINT PREVIEW
   OLD: "A 5-second auto-reverting zoom. No actual print/PDF output from it."
   ACTUAL: Fully replaced. `enterPreviewMode()` saves current grid/safe-zone states,
   hides grid layer, safe zone, and all text-highlight rects, zooms to 0.5×, and
   changes the preview button to a yellow "exit" state. `exitPreviewMode()` restores
   all prior state including grid visibility, safe zone, and zoom. No auto-timer.
   STATUS: COMPLETE ✅

3. APP SETTINGS PERSISTENCE
   OLD: "`saveAppSettings` builds the object but never saves it. Left/right panel
   visibility resets on reload."
   ACTUAL: `saveAppSettings()` in exports.js reads `.classList.contains("hidden")`
   without any side effects and persists to sessionStorage as JSON. `loadAppSettings()`
   reads it back and applies the hidden class on load. It is wired into `onloadInit()`
   so it runs on every page load. Panel state now survives reloads.
   STATUS: COMPLETE ✅

4. TEMPLATE LOADING — IMAGE ELEMENTS
   OLD: "Image elements use URL.createObjectURL(element.src) on a stored File object,
   which won't survive IndexedDB serialisation. Images will silently fail on reload."
   ACTUAL: Fixed. `getImageUrl()` now uses `FileReader.readAsDataURL()` returning a
   Promise<base64 data URL>. The image input handler converts to base64 before calling
   `addImageBox`, so images stored in templates are proper data URLs.
   `loadSelectedTemplateFile` uses `element.src` directly (no createObjectURL).
   STATUS: FIXED ✅
   CAVEAT: `saveCustomTemplate()` in letters.js still stores the raw `File` object
   (not base64) for image elements in custom templates. Images saved via the custom
   template creator will still break after reload. Text and table elements are fine.

5. CUSTOM TEMPLATE CREATOR
   OLD: "Large portions are commented out, suggesting it was being rebuilt."
   ACTUAL: The large commented-out block has been replaced with working code.
   `saveCustomTemplate()` now handles text, image, and table element extraction with
   proper per-type validation. `reIndexElements()` re-numbers elements on removal.
   Form builds dynamically via `addDocumentElement()`. Saves to IndexedDB and logs
   to audit.
   STATUS: SUBSTANTIALLY COMPLETE ✅ (image-in-template still uses raw File object —
   see Caveat above)

--- Previously listed as "Missing but Clearly Intended" ---

6. PDF EXPORT
   OLD: "No 'Save as PDF' for the actual canvas. The function doesn't exist yet."
   ACTUAL: Fully implemented. `exportAsPDF(fileName)` in scripts.js:
   — Adds `export-mode` class to body (hides UI chrome via CSS)
   — Calls html2canvas at scale 3 (crisp A4 print resolution)
   — Uses `onclone` callback to suppress contextMenu, imageInput, and all
     .text-highlight rects in the captured clone
   — Uses `ignoreElements` to strip rulers-layer, grid-layer, contextMenu, imageInput
   — Creates jsPDF with exact page dimensions from pageDimensions[currentPageSize]
   — Saves the file with user-supplied filename via modal
   Wired to `openExportModal()` → `confirmExportPDF()` → `exportAsPDF()`.
   STATUS: COMPLETE ✅

7. UNDO / REDO
   OLD: "No history stack exists for canvas actions."
   ACTUAL: Fully implemented. `_undoStack` / `_redoStack` arrays (20-entry cap each).
   `captureSnapshot()` serialises the content-layer to JSON and pushes to _undoStack.
   `undo()` moves current state to _redoStack and restores previous. `redo()` reverses.
   `_applySnapshot()` reconstructs DOM and re-attaches all interactions.
   Snapshot is captured before: addTextBox, addTableBox, addImageBox, removeElement,
   drag-end (onUp), z-order changes, alignment changes.
   Keyboard: Ctrl+Z = undo, Ctrl+Y / Ctrl+Shift+Z = redo (Mac: Cmd+Z etc.)
   STATUS: COMPLETE ✅

8. ELEMENT LAYERING (Z-ORDER)
   OLD: "No bring-forward / send-back controls visible in the codebase."
   ACTUAL: Fully implemented. Four functions in scripts.js: `bringToFront`,
   `bringForward`, `sendBack`, `sendToBack`. All manipulate SVG DOM child order
   (later sibling = visually on top) and call captureSnapshot() before mutating.
   Exposed via a "Layer Order" button row in the shared context menu section,
   appended to all three element types (textBox, imageBox, tableBox).
   STATUS: COMPLETE ✅

9. TEXT FORMATTING CONTROLS
   OLD: "Font family, size, bold, italic, colour are not exposed as UI controls."
   ACTUAL: Partially implemented. The textBox context menu now exposes:
   — Font size (numeric input, calls `changeTextBoxFontSize` which rewraps text)
   — Bold toggle (switch, calls `toggleBoldFont` via CSS class)
   — Italic toggle (switch, calls `toggleItalicFont` via CSS class)
   Text content is editable inline.
   Still missing: font family selector, text colour picker.
   STATUS: PARTIAL ⚠️ (size, bold, italic done — family and colour remain)

10. IMAGE RESIZING
    OLD: "No aspect-ratio-aware resize handle logic was seen."
    ACTUAL: Partially implemented. The imageBox context menu now has:
    — Width × Height inputs in mm
    — Aspect-ratio lock checkbox (auto-updates height as width is typed)
    — `toggleImageResize()` applies the new dimensions with bounds-checking
    — Rotate input (0–360° in 90° steps) via `rotateImageAngle()`
    — Flip Horizontal toggle via `toggleImageFlip()`
    Still missing: on-canvas drag handles (resize still requires the context menu).
    STATUS: PARTIAL ⚠️ (resize/rotate/flip via context menu work — drag handles absent)

11. SNAP TO GRID
    OLD: "Grid is visual only, no snap-on-drag behaviour."
    ACTUAL: Fully implemented. `toggleSnapToGrid()` persists a flag in sessionStorage.
    The `onMove` drag handler reads `snapToGrid === "true"` and rounds updatedX/Y to
    the nearest grid step size before applying the translate. Also warns via toast when
    crossing the safe zone boundary during drag.
    STATUS: COMPLETE ✅

12. ALIGNMENT TOOLS
    OLD: "No align left/right/centre/distribute for multiple elements."
    ACTUAL: Fully implemented. Six functions: `alignLeft`, `alignCentreH`, `alignRight`,
    `alignTop`, `alignMiddleV`, `alignBottom`. They convert pixel positions to mm using
    the pageRect bounding rect, then adjust the element's translate() transform.
    All call captureSnapshot() first. Exposed in the shared context menu as an
    "Align to Page" button row.
    STATUS: COMPLETE ✅ (distribute-between-elements not done, but align-to-page is)

========================================================
SECTION 2 — WHAT IS STILL ACTUALLY INCOMPLETE
========================================================

1. CUSTOM TEMPLATE IMAGE STORAGE (Medium)
   saveCustomTemplate() in letters.js stores `src: file` (raw File object) not
   base64. File objects are not serialisable by IndexedDB's structured clone algorithm —
   they survive the current session but silently lose data on the next open.
   Fix: call getImageUrl(file) and await the base64 result before pushing to elements[].

2. TEXT COLOUR / FONT FAMILY (Low-Medium)
   The textBox context menu has size, bold, italic — but no colour picker and no
   font family dropdown. These would complete the formatting panel.

3. CANVAS RESIZE DRAG HANDLES (Low)
   Image resize works via the context menu (with aspect ratio lock), but there are
   no on-canvas corner/edge drag handles. The addResizeHandle() function in scripts.js
   creates a .resize-img-handle div, but it operates on CSS box model properties
   (dataset.widthMm, dataset.heightMm) which don't apply to SVG <image> elements.
   The context-menu resize path is the working one.

4. STATS RESET ON CANVAS RESET (Low)
   setDefaults() resets the stats object on every onloadInit() call, so element
   counters (and fileExports/fileImports counts) are wiped whenever the canvas is
   reset. The stats reset and layout reset are conflated inside setDefaults().
   Fix: separate the two concerns — only reset stats on a user-initiated "new document"
   action, not on every init.

5. DB CONNECTION NOT CACHED (Low — performance)
   initDB() opens a fresh IndexedDB connection on every single DB call. The connection
   should be opened once and reused. Under normal usage this is not noticeable, but
   the setInterval polling in stats.js (every 5 seconds, opens 3 transactions) means
   ~36 connection-open cycles per minute that could be eliminated.

6. SETINTERVAL POLLING IN STATS.JS (Low — performance)
   checkStorage(), loadAuditHistory(), loadVersionHistory() all run every 5 seconds
   regardless of whether anything has changed. Should be replaced with event-driven
   updates (call them only after a write completes).

7. FONT FAMILY SELECTOR (Low)
   No UI to change SVG font-family. Would require a <select> in the textBox context
   menu and setting the font-family attribute on the text element.

8. MULTI-PAGE SUPPORT (Not started — scope question)
   Still single-page. For the letter/invoice use case this is generally fine unless
   body text overflows. Not a blocker for v1 if content fits a single page.

9. AUTO-SAVE (Not started)
   Manual version save exists. Auto-save on a timer or on every change is not
   implemented. Low priority given undo/redo now exists.

10. COLLABORATION / CLOUD SYNC (Not started — out of scope for v1)
    Everything is IndexedDB/sessionStorage local only. No change here; still expected.

========================================================
SECTION 3 — FEATURES ADDED THAT WERE NOT IN OLD ASSESSMENT
========================================================

These are net-new capabilities not mentioned in the previous assessment:

- Lock/Unlock All Elements — toggleLockAllElements() locks all .design-object
  elements (locked elements ignore drag and context menu). Button icon toggles.

- Element Counters in UI — Live badge counters for text/image/table elements
  (elemCountText, elemCountImage, elemCountTable) updated on add/remove.

- Overlap Warning — checkElementOverlap() warns via toast when a dragged element
  lands on top of another element.

- Safe Zone Crossing Warning — During drag, a throttled toast warns when the element
  crosses the 10mm safe zone boundary.

- Image Rotate + Flip — rotateImageAngle() and toggleImageFlip() in image context menu.

- Envelope Presets — Full layout data for DL_E, C5_E, Num10_E envelopes in letters.js
  (addEnvelopeElements). Previously only Letter/Invoice were populated.

- DPI Verification — getEffectiveDpi() in layout.js reports effective screen DPI of
  the current canvas rendering. Informational tool for print quality awareness.

- changeTableCellTextContent — Table cells editable via context menu inline input,
  not just via prompt(). (Also note: makeTableEditable() using prompt() is commented out.)

- Custom Template now handles table elements — saveCustomTemplate() extracts and
  stores table element config in addition to text and image.

========================================================
SECTION 4 — OVERALL COMPLETION RE-RATING
========================================================

Previous rating: ~50-60% of a usable v1
Current rating:  ~75-80% of a usable v1

The most critical gap from the old assessment — PDF export — is now done.
Undo/Redo, z-order, alignment, snap-to-grid, version restore, and preview mode
are all shipped. The remaining work is:
  - 2 UI additions (font family, text colour)
  - 1 data bug (image storage in custom templates)
  - 2 performance cleanups (DB caching, setInterval)
  - 1 UX gap (canvas resize drag handles)

None of these block the primary use case (compose a letter/invoice/envelope,
export as PDF or SVG, save a version). The app is usably functional for that
workflow today.

Suggested priority order for remaining work:
  1. Fix image storage in saveCustomTemplate() — data integrity issue
  2. DB connection caching + remove setInterval — performance/reliability
  3. Font colour + font family in text context menu — completeness
  4. Canvas drag handles for image resize — UX polish
  5. Stats reset separation from layout reset — minor correctness fix
